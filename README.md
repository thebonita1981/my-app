# my-app

## テトリス風パズルゲーム

`index.html` を開くだけで遊べる、HTML/CSS/JavaScript 単一ファイルのテトリス風パズルゲームです。

### 遊び方

1. `index.html` をブラウザで開きます（ダブルクリックでOK、サーバー不要）。
2. 7種類のテトリミノ（I, O, T, S, Z, J, L）がランダムに上から落ちてきます。
3. 横一列がすべて埋まるとその列が消え、消した行数に応じてスコアが加算されます。
4. ブロックが積み上がって画面上部に到達するとゲームオーバーになります。
5. ゲームオーバー画面の「もう一度プレイ」ボタンでリスタートできます。

### 操作方法（PC）

| キー | 動作 |
| --- | --- |
| ← / → | ブロックを左右に移動 |
| ↓ | ソフトドロップ（高速落下） |
| ↑ または スペース | ブロックを回転 |
| P | 一時停止 / 再開 |

### 操作方法（スマホ・タブレット）

画面下部に表示される方向ボタンで操作できます。

- ◀ / ▶ : 左右移動
- ▼ : ソフトドロップ
- ⟳ : 回転

### BGM（効果音）

- プレイ中はWeb Audio APIで生成したオリジナルの電子音メロディがループ再生されます（外部音声ファイルは使用していません）。
- 画面上部の「🔊 BGM」ボタンでオン/オフを切り替えられます（設定はブラウザに保存され、次回起動時も引き継がれます）。
- ゲームオーバーになるとBGMは自動的に停止します。一時停止中も停止し、再開すると再び鳴り始めます。
- ブラウザの自動再生制限のため、画面を最初にタップ/クリックまたはキー操作した時点でBGMが鳴り始めます。
- Web Audio APIで直接音を生成しているため、スマホのマナーモード（サイレントスイッチ）がオンの場合はBGMも鳴りません。

### 難易度の自動上昇

- 画面上部に「経過時間」が表示され、プレイ開始からの時間がわかります。
- プレイ開始から2分経過するごとに、ブロックの落下速度が少しずつ段階的に速くなります（最小落下間隔には下限があり、無限に速くなり続けることはありません）。
- ラインを10ライン消すごとに上がる「レベル」表示でも、現在の難易度の目安を確認できます。

### その他

- 画面右側（スマホでは下側の情報パネル）にスコア・消去ライン数・レベル・経過時間・次のミノ（ネクスト）が表示されます。
- ラインを消すごとにレベルが上がり、落下速度が徐々に速くなります。
