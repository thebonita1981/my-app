# my-app

## ひらがなスタンプらりー

`index.html` を開くだけで遊べる、HTML/CSS/JavaScript 単一ファイルの子供向けひらがな学習アプリです。「スタンプラリー」形式で、あ行〜わ行の基本46文字を楽しく覚えられます。

### 遊び方

1. `index.html` をブラウザで開きます（ダブルクリックでOK、サーバー不要）。
2. ホーム画面（スタンプ帳）に「あ行」〜「わ行」の10行がグリッド表示されます。行をタップすると、その行の練習が始まります。
3. ひらがなが1文字ずつ出題されます。正解すると次の文字に進み、間違えた文字は後でもう一度出題されます（復習の仕組み）。
4. 1行（5文字前後）をすべて正解すると、御朱印風のスタンプが押される演出とともにクリア画面が表示されます。
5. 達成した行はスタンプ帳に記録され、ブラウザを閉じても進捗が保持されます。

### 出題モード（タブで切り替え）

- **えらぶモード**：表示されたひらがなに対して、ローマ字の4択ボタンから正解を選びます。
- **はなすモード**：表示されたひらがなを声に出して読み、音声認識（Web Speech API）で発音をチェックします。マイク・音声認識に対応していない端末では、このタブは自動的に非表示になります。

### 音声機能

- 問題が出るたびに、ブラウザの音声合成（Speech Synthesis API）でひらがなが自動読み上げられます。
- 画面右上の🔊ボタンで自動読み上げのオン/オフを切り替えられます（設定はブラウザに保存されます）。カードの下の「もういちど きく」ボタンからはいつでも手動で再生できます。
- はなすモードでは、マイクボタンをタップして発音すると、認識結果とお手本の文字を比較して正解・不正解を判定します。

### フィードバック演出

- 正解時：カードがポップするアニメーションと明るいチャイム音、スタンプ帳への記録。
- 不正解時：カードがシェイクするアニメーションとブザー音、正解の選択肢のハイライト表示。
- 行クリア時：御朱印風スタンプが「ペタン」と押される演出、紙吹雪アニメーション、専用の効果音。

### その他

- 丸みのある可愛らしいフォント（Kosugi Maru）と、ピンク・水色・クリーム系の子供向け配色を採用。
- スマートフォンでの利用を想定し、画面サイズに応じて自動的にレイアウトが調整されるモバイル最適化デザインです。
- 学習の進捗（達成した行）は `localStorage` に保存され、次回起動時も引き継がれます。
